Дата: 2026-10-14. Проверка выполнена заново по первоначальному извлечённому тексту обеих страниц задания, сохранённому в истории первого чтения до удаления PDF. Прежний вывод о готовности не использовался как доказательство. Оригинальный PDF не восстановлен в проекте.

Объём: локальный API, архив, Gatling, сравнение JVM/Native Image и очистка. Публикацию репозитория автор оставил за собой. Отправка HR не разрешена и не выполнялась.

## Исправлено при этой сверке

1. **Повторный запуск нагрузки мог только перечитать готовые результаты.** Теперь запуск без `--output` создаёт новую UTC-папку и реально запускает нагрузку. Продолжение существующих результатов требует явного пути, совпадения конфигурации и сообщает `RESUME`. Незавершённые файлы не перезаписываются. Новый короткий JVM/Native smoke реально выполнен; он не входит в основную матрицу 30s/60s.
2. **Отчёт новой папки мог ссылаться на отсутствующие metadata-файлы.** Renderer теперь показывает только существующие свидетельства и не переносит утверждения о проверках из другого запуска.
3. **«200/10000 символов» не уточняло фактическую единицу.** API использует UTF-16 code units; реальный тест принял 100 эмодзи и отклонил 101 для name. README/OpenAPI теперь явно описывают дополнительные UTF-16 ограничения; бизнес-логика не менялась.

## Границы подтверждения

- Инварианты приоритетов относятся к состояниям, доступным через API и после commit. UNIQUE отложен до commit; внутри незавершённой транзакции перестановка может временно содержать повторяющийся номер. Если работодатель подразумевает запрет даже на внутренние промежуточные состояния, это отдельное требование, которого текущий алгоритм буквально не обеспечивает.
- RSS и число потоков — максимумы среди снимков раз в 5s. Newly observed thread IDs — нижняя оценка новых потоков, не точный счёт всех рождений: короткоживущие потоки между снимками могут быть пропущены. Точный полный счёт рождений Native-потоков не доказан.
- JVM — Temurin 17.0.20.1, Native — GraalVM CE 17.0.9; Java patch-версии различаются. Один прогон на профиль и общий локальный хост не доказывают статистическую значимость или production SLA.
- Проверка двух service-экземпляров использует реальный PostgreSQL в одном тестовом процессе. Два независимых HTTP-процесса одновременно не поднимались; межпроцессная блокировка подтверждается механизмом PostgreSQL, а не отдельным двухконтейнерным экспериментом.
- В задании указаны ориентир 6h и максимум 8h. Точные активные человекочасы не учитывались; соблюдение этого организационного условия не удостоверяется тестами.
- Архив готов, но отправка HR и публикация GitHub/GitLab не выполнены по согласованному локальному объёму. Эти действия нельзя помечать как выполненные.
