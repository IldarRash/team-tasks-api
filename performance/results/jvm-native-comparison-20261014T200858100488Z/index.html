How to read this report

TPS counts completed four-request lifecycles: POST, priority PATCH, GET list, then DELETE. RPS counts the individual HTTP requests in those lifecycles.

RSS is process resident memory observed by the common collector. It is not JVM heap and must not be read as Docker working-set memory.

Newly observed thread IDs exclude threads born and ended between 5 s samples. Generator RSS and OS threads describe the load generator, separate from the API footprint.

JFR and NMT are JVM-only diagnostics. Native Image does not substitute zeroes for unavailable JVM instrumentation, so they are intentionally absent from this cross-runtime matrix.

Comparability boundary. This dashboard compares the paired request/load measurements and the common OS/container collection path. It does not make JVM-only heap, JFR, or Native Memory Tracking data equivalent to Native Image metrics.
