Как читать потоки

OS threads max — пиковая одновременность, замеченная 5-секундным опросом. Поток, который начался и завершился между выборками, в неё может не попасть.

Точно созданы — рождения OS-потоков в измерительном HTTP-окне. Итого охватывает запуск API и все фазы до окончания захвата.

Главный поток API уже существовал до старта трассы и не является рождением CLONE_THREAD. Поэтому tracer видит на один отдельный API OS-поток больше, чем Итого.

Значение warm-up может отсутствовать, когда граница окна попала в неопределённость калибровки часов. Это не означает ноль потоков.
